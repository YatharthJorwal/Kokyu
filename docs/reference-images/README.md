# Reference images

Design targets for later UI work. They are not shipped. Generated by the owner with GPT Image (2026-11-15).

| File | What it shows |
|---|---|
| `chat-ui.webp` | The chat window: sidebar, companion chip, model popover (Local and API sections, effort slider, spend), composer and model chip |
| `stage-view.webp` | The stage view: companion bust-up, top-bar chips, "Enter 3D Space", overlay composer |
| `icon/app-icon.webp` | Proposed app icon (1254×1254) |

The icon file has no transparency: the corners outside the rounded tile are opaque black. Before running `npm run tauri icon` on it, get a transparent 1024×1024 PNG. When it becomes the app icon, update the icon row in `docs/THIRD-PARTY.md`.
